# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Do not harass anyone. Do not post secrets, tokens, or other people's customer data in issues or pull requests.

Report unacceptable behavior by opening a private security note in [SECURITY.md](SECURITY.md), not a public issue.
